# Eyelash Corne на Mac: как устроено и как обслуживать

Ветка `mac-aerospace` в форке `punjet/zmk-new_corne`. Прошивка работает только вместе с правилами Karabiner-Elements из [`karabiner/`](karabiner/README.md). Раскладки на Mac: ABC и RussianWin. Окнами управляет AeroSpace (его конфиг лежит в `~/dotfiles/aerospace`).

## Что где лежит

| Путь | Что это |
|---|---|
| `config/eyelash_corne.keymap` | раскладка: слои, аккорды, hold-tap, макросы |
| `config/eyelash_corne.conf` | общие настройки обеих половин (NKRO, подсветка, сон, debounce) |
| `boards/shields/eyelash_corne/*_left.conf`, `*_right.conf` | настройки отдельных половин (Studio, батарея, экран) |
| `karabiner/corne.json`, `karabiner/sync.py` | правила Karabiner, без которых раскладка не работает |
| `cheatsheet/cheatsheet.py` → `cheatsheet/Corne-шпаргалка.pdf` | шпаргалка по всем слоям |
| `scripts/flash.sh` | скачать сборку и прошить половину |

## Слои и ключевые клавиши

| Клавиша | Тап | Удержание |
|---|---|---|
| левый FN (левый большой, средний) | Pause → Karabiner переключает ABC ↔ RussianWin | слой NUM |
| правый FN (правый большой, средний) | — | Left Option + слой AERO → Karabiner делает Hyper (⌘⌃⌥) для AeroSpace; в Logic Pro и Final Cut Pro — обычный Option |
| крайний правый большой | Esc | Right Option; в Logic Pro и Final Cut Pro — Hyper |
| левый Shift | Shift | двойной тап — Caps Lock (Karabiner превращает его в Hyper) |

- **NUM** (держишь левый FN): цифры, символы, стрелки на H J K L, Home/End/PgUp/PgDn. На левом нижнем ряду ⌘Z ⌘X ⌘C ⌘V и «удалить слово», на правом громкость и Prev. Правый Enter работает как ⌘. Правый FN остаётся Hyper, так что оба FN + цифра — это рабочие пространства AeroSpace, в любом порядке нажатия.
- **Fn** (левый FN + крайний правый): F1–F12, Bluetooth-профили, USB/BLE, яркость экрана, Play/Next, подсветка, Boot (C или `,`), Reset.
- **AERO** (держишь правый FN): всё прозрачное, AeroSpace получает Hyper + клавишу. Правый FN + Space открывает Sol.

Аккорды:

| Аккорд | Результат | Условия |
|---|---|---|
| `asdf` | `.` | окно 60 мс, не срабатывает в первые 150 мс после печати, только QWERTY |
| `jkl;` | `,` | то же |
| левый FN + `F`+`D` / `J`+`K` | слово влево / вправо (⌥← / ⌥→) | только в слое NUM |
| левый Cmd + левый FN | чистый Option, пока держишь | для Option+клика трекпадом |
| все 6 больших пальцев | заблокировать Mac (⌃⌘Q) | окно 80 мс |
| `Q`+`S`+`Z` | выключить (soft off) | держать 2 с |

Подробно, со схемами, — в шпаргалке.

## Изменить раскладку и прошить

1. Правишь `config/eyelash_corne.keymap`, коммитишь и пушишь в `mac-aerospace`. GitHub Actions соберёт прошивку за ~4 минуты.
2. Прошиваешь:
   ```sh
   scripts/flash.sh left            # последняя успешная сборка ветки
   ```
   Скрипт находит сборку, скачивает её в `~/.cache/corne-firmware/` и ждёт диск NICENANO. Подключи половину по USB и дважды быстро нажми reset (или: левый FN + крайний правый палец, затем **C** на левой половине / **`,`** на правой).
3. **Какую половину прошивать.** Раскладка, аккорды и макросы живут в **левой** половине (она главная), поэтому почти всегда хватает левой. Правую прошиваешь, только если менялись её настройки в `*_right.conf` или экран.
4. Ошибки `cp` вроде `Device not configured` или `fchmod failed` безвредны: плата перезагружается сразу после записи файла. Признак успеха — диск NICENANO пропадает.

## Откат

```sh
scripts/flash.sh left 75e3add    # прошить сборку конкретного коммита
```

`75e3add` — проверенная рабочая прошивка до всех изменений, сделанных 2026-11-06. Подойдёт любой коммит ветки, у которого есть успешная сборка.

## Karabiner

```sh
python3 karabiner/sync.py install   # правила из репо → ~/.config/karabiner/karabiner.json
python3 karabiner/sync.py export    # текущие правила с Mac → karabiner/corne.json (потом коммит)
```

Правила срабатывают только для Corne (vendor 7504 / product 24926). Таблица «какая клавиша во что превращается» — в [`karabiner/README.md`](karabiner/README.md).

## Шпаргалка

```sh
python3 cheatsheet/cheatsheet.py
```

Геометрию клавиш скрипт берёт из `config/eyelash_corne.json`, номер коммита — из git. **Подписи на клавишах записаны прямо в скрипте**, поэтому после изменения раскладки их нужно поправить в `cheatsheet.py`. Нужны `reportlab`, `fonttools` и шрифты Arial из macOS.

## Грабли, на которые уже наступили

- **Не переключать NKRO** (`CONFIG_ZMK_HID_REPORT_TYPE_NKRO` в `eyelash_corne.conf`). Когда его выключили, macOS по Bluetooth продолжила ждать данные в старом формате, и клавиатура перестала печатать совсем. По USB тоже ничего не было: вывод был выбран на BLE. Помог только откат прошивки.
- **Не использовать F13–F24.** В режиме NKRO по умолчанию ZMK их не отправляет, клавиша просто молчит. Расширенный режим NKRO их включает, но ломает Bluetooth по той же причине, что выше. Для сигналов в Karabiner бери клавиши с кодом ≤ 0x67, которых нет у Mac: Pause, Scroll Lock, Print Screen, Insert, Application, клавиши цифрового блока (Keypad 0–3 и `=` уже заняты).
- **Не слать из прошивки Left Option с клавишей** (`LA(...)`): Karabiner превратит Option в Hyper. Right Option (`RA(...)`) в Logic Pro и Final Cut Pro тоже становится Hyper. Option-сочетания делай через отдельную клавишу, которую Karabiner превращает в нужное сочетание (так сделаны «удалить слово» и прыжки по словам).
- **Не ставить на правый FN в слое NUM ничего, кроме `&trans`.** Если левый FN включит слой первым, правый FN сработает как эта клавиша вместо Hyper, и AeroSpace перестанет получать оба FN + цифру.
- **Аккорды в слое NUM и левый FN.** Левый FN работает в режиме `balanced` (250 мс): слой включается, только когда другую клавишу нажали и отпустили или прошло 250 мс. Если аккорд в NUM пропускается, причина, скорее всего, здесь.
- **Повторы букв («аааа»)** чаще всего бывают, когда AirPods загружают Bluetooth и сигнал об отпускании клавиши опаздывает. Помогает увеличить «Задержку перед повтором» в настройках клавиатуры macOS. Если повторы бывают и без наушников, смотри, на какой половине.
- **Энкодера физически нет.** `sensor-bindings` и EC11 остались в конфиге от исходной прошивки и ни на что не влияют.
